# 🏎️ My Racing Game

**My Racing Game** — аркадна гоночна гра на Python з Pygame. Керуй автомобілем, уникни ворогів та збирай бонуси для збільшення рахунку. Пауза — SPACE, рестарт після поразки — ENTER, вихід — ESC. Щоб запустити гру: клонувати репозиторій `git clone https://github.com/ViktorPro1/my_racing_game.git` і перейти в папку `cd my_racing_game`. Рекомендується створити віртуальне середовище: `python3 -m venv .venv` та активувати його (`source .venv/bin/activate` для Linux/macOS або `.venv\Scripts\activate` для Windows). Встановити Pygame: `pip install pygame`. Запуск: `python main.py`. У папці `assets/` повинні бути файли: фон, машини, бонуси, музика. Якщо файли відсутні, гра створює базові графічні об'єкти автоматично. Мета гри — уникати ворогів, збирати бонуси та набирати максимальний рахунок. Насолоджуйся грою!
